# Database Schema

Source of truth: [`prisma/schema.prisma`](../../prisma/schema.prisma). Current migration:
`20261001151350_init`. Engine: MySQL 8, InnoDB, `utf8mb4` / `utf8mb4_unicode_ci`.

Conventions:
- Primary keys are CUIDs (`VARCHAR(191)`), generated by Prisma.
- Timestamps are `DATETIME(3)` in UTC; `createdAt` defaults to now, `updatedAt` is maintained by Prisma.
- Enums are native MySQL `ENUM` columns; their labels/colours live in code
  (`lib/applications/status.ts`, `lib/applications/source.ts`, `lib/email/delivery-status.ts`).
- MySQL has no array type, so lists are either normalised tables (tech stack) or
  comma-separated text (CC/BCC addresses).

## Document

A file in the document library.

| Column | Type | Null | Notes |
| --- | --- | --- | --- |
| `id` | VARCHAR(191) | no | PK |
| `name` | VARCHAR(200) | no | display name ("Backend Developer CV") |
| `type` | ENUM DocumentType | no | |
| `storageKey` | VARCHAR(500) | no | **Unique.** Key in the storage backend (`2026/10/<uuid>.pdf`) — not a public URL |
| `originalFilename` | VARCHAR(255) | no | sanitised; used as the attachment filename |
| `mimeType` | VARCHAR(100) | no | derived from validated content, not the browser |
| `size` | INT | no | bytes (≤ 5 MB) |
| `isDefault` | BOOLEAN | no | at most one default per type (enforced in the service) |
| `createdAt`, `updatedAt` | DATETIME(3) | no | |

Index: (`type`, `isDefault`).

> The specification listed `applicationId` and `url` on Document. Documents are a reusable
> library instead (one CV used by many applications) linked through `ApplicationDocument`,
> and `storageKey` replaces `url` because files are private. See
> [ADR-005](../decisions/adr-005-normalised-tech-stack-and-document-library.md) and
> [ADR-007](../decisions/adr-007-local-document-storage.md).
